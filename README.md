### 🌐 Network Security Scanner

A safe and educational Python TCP connect scanner for authorized systems.

- Localhost and private-network scanning by default
- Explicit permission flag for public targets
- ThreadPoolExecutor-based concurrent scanning
- Timeout and rate-limit controls
- Common service identification
- Passive TCP banner grabbing
- Exposure-based risk ratings
- Terminal, JSON, and CSV reports
- Local scan logging
- No exploitation, brute force, stealth, or CVE lookup

[View the Network Security Scanner](https://github.com/ayushkulhari47/network-vulnerability-scanner)
